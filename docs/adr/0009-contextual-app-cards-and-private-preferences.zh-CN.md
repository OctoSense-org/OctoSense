# ADR 0009：情境应用卡片与私有偏好记忆

[English](0009-contextual-app-cards-and-private-preferences.md) | 简体中文

状态：已接受，本次变更已实现（2026-10-06）。设备和模型验收单独记录；本决策
不声称所有流程都已通过验收。

## 所需行为

News、Photos 和 YouTube 以应用身份发布 Glance 卡片，包含紧凑摘要、独立展开
工作区及原生 Card/Chat。展开保留内容身份与上下文，其他卡片不挤占当前任务的
空间。其他应用代理通过已声明、授权、准入的工具及既有中继调用所有者服务，
不直接读取另一个应用的文件。

每条新闻提供 Research topic。UI 与 News 代理调用同一个所有者服务，使用既有
octos 研究 toolbox，在搜索、阅读、模型预算内生成带来源的卡片。展开显示完整
已校验总结。研究按请求触发，不为每条抓取的标题自动调用模型；失败和部分结果
必须明确显示。

Photos 暴露实际拥有的图库、集合及稳定内容身份。当前 75 张内置照片必须标为
示例；未实现导入和权限流程，不能声称读取 Android 相册。卡片可打开对应照片
并进行上下文聊天。不因拥有元数据就向模型发送照片像素。

YouTube 在早晨、中午、下午休息、晚餐、睡前提供音乐推荐。五个时段可配置，
使用设备本地时区；Daily music 需主动开启且应用代理须已获得同意。定时器在
宿主进程运行，Android 可能暂停它；这不是 Android 后台任务。服务搜索真实
YouTube 视频，发布已解析 ID，不能虚构 ID 或声称每次定时选择都由模型完成。
应用代理可用同一组工具选择、调整并发布。只有用户点击才进入既有播放器；
定时器不播放，重试不反复通知，也不保证绕过内容或平台播放限制。

## 代理与记忆边界

宿主服务持有业务状态，暴露范围明确的工具。所有者声明、调用者请求、App Hub
准入授权、身份检查和冷启动执行器必须一起更新。沿用每应用、每账号一个 peer
及宿主绑定的卡片上下文；卡片代码不能制造授权或批准。

成功的人类 Card/Chat 回合后，有上限的队列与模型预算可提取最新人类消息中的
简短、明确偏好。模型挑选完整原文陈述，宿主拒绝改写、敏感事实和无依据推断。
不保存整段对话、凭据、文章指令、照片元数据或助手的猜测；不是每次对话都有
记忆。写入前复查同意状态及账号，以散列形式保留应用、账号、上下文来源并去重。

偏好存储在应用沙箱之外的 `apps/.host/system-memory/`，仅系统会话可调用
`preferences.list/forget/configure`，修改须由人类触发系统回合。当前固定的
octos Recall API 没有删除方法；为保证遗忘有效，不向 Recall 复制数据，系统
代理个性化时读取这里的权威存储。遗忘会使待写入结果失效，并阻止相同陈述重试
恢复，但不删除原始聊天或其他内核记忆。其他应用代理不能读取全局偏好列表。

跨应用准入授权在冷启动的 bundle/代理发现之前注册。服务解析自己保存的新闻、
照片和视频身份，以所有者身份发布。研究完成时检查原始发布实例，防止晚到结果
恢复已关闭卡片或覆盖新请求。App Hub 先在独立暂存目录解包并验证，再原子安装，
并发发现不能看到半成品 bundle。

## 验收

覆盖冷启动跨应用调用、拒绝未授权调用、内容导航、摘要展开、完整研究结果和
引用、聊天输入与状态、时段去重、点击播放、偏好来源与遗忘。桌面迭代使用自有
隐藏 Makepad 实例，手机验收使用指定 OnePlus 6；提交的样例使用虚构内容。
Codex 编写运行时和工具集成，模型内容单独标注，不把操作员测试说成自主代理测试。

本 ADR 不给出 UX 分数或手机、模型全通过结论。交付记录必须列明源码、构建、
实际检查和未验证范围。用户行为与存储边界见[情境卡片指南](../contextual-app-cards.zh-CN.md)。
