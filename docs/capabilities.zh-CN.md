# 应用能力声明与执行边界

[English](capabilities.md) | 简体中文

能力声明描述应用的预期用途。公开调用遵守已验证的应用身份、私有存储边界、
账户范围及真实用户同意；清单中的服务族和目的地列表用于披露用途。

这项策略已随[桌面 RC4](https://github.com/OctoSense-org/OctoSense/releases/tag/desktop-v0.1.0-rc.4)
发布，源码为 `9266b008`。[源码与归档包验收](../tools/fixtures/wasm-phone-lab/README.zh-CN.md#rc4-发布证据)
分别记录。RC2 和 Home beta.2 早于此策略；独立手机测试不会升级已安装的 Home。

## 声明用于说明用途

应用的 `capabilities` 和 `network.hosts` 用于能力发现、商店说明和审核。
没有声明某个公开 API 家族，不会因此拒绝调用。添加声明也不代表用户同意、
账户已连接或写操作获准。仍应准确填写声明，帮助用户理解应用的用途。

此规则适用于应用的 Splash 请求、自带的 Wasm 函数及组件，以及应用 Agent
提供的宿主服务工具。这些入口使用相同的应用身份，但交互限制不同：Agent 和
组件不能打开权限面板，也不能冒充用户的真实输入。

`requires` 与 `host_api.required` 是兼容性要求。缺少所需 ABI 或方法的宿主
仍会拒绝安装应用。可选方法通过 `runtime.describe` 查询。能力声明或 Wasm
封装都不能凭空提供宿主中不存在的 API。

## 操作仍须满足的条件

| 边界 | 宿主检查的内容 |
| --- | --- |
| 应用身份 | 已验证的安装包、当前准入状态，以及宿主提供的应用 ID 和配置目录。撤回、篡改或更新会使旧任务失效。 |
| 设备访问 | 每个应用的用户同意和操作系统权限。系统授予 OctoSense 的权限不自动覆盖所有应用。权限申请必须来自前台应用。 |
| 账户数据 | 应用自己的已连接账户及当前账户绑定。脚本或模型参数不能选择另一个应用的账户。 |
| 私密写操作 | 发送邮件、修改日历和保存 GitHub 内容仍需宿主审核面板及可信用户输入。后台回调不能批准。 |
| 应用文件 | 应用存储隔离目录、当前账户、配额和资源生命周期。组件只能看到应用目录，不能看到宿主文件系统。 |
| 应用助手 | 应用确实提供助手、用户同意，以及受支持的公开方法。能力声明本身不会创建助手。 |
| 跨应用工具 | 已提供的工具、其所有者、共享授权和风险规则。移除家族检查不等于授予其他应用的工具。 |
| 资源与平台限制 | 服务已经编译进宿主、平台支持、输入输出大小上限、期限、配额和取消机制。 |

运行时读取宿主私有资料和发送无归属 Agent 通知的接口属于内部接口，不是公开
应用能力。应用应使用带身份和账户范围的宿主 API 与应用 Agent 代理层。
网页内容也保留自身的沙箱和请求校验；移除清单中的主机名单限制不等于移除这些边界。

执行卡片源码前，App Hub 的 `apply_device_consent` 将已验证启动包的应用 ID 绑定到隔离实例，
并启用设备同意边界。仅有存储目录还不够：原生文件和媒体服务获取存储句柄时，也要求该实例
具有相同的应用身份。启动失败时会清除旧身份；脚本不能提供替代的应用 ID。

## 验证与发布

验收矩阵成对测试“已声明”和“未声明”的调用，再独立测试拒绝设备同意、外部
配置目录、旧账户、未经批准的写操作、存储越界及配额耗尽。组件验收还检查实际
商店解析、别名调用、实例状态隔离和撤回。

源码 `8b09e05d` 的完整桌面 App Hub/组件演练通过 11/11 项检查，原生 Host API Lab
通过 31/31 项。在指定的 OnePlus 6 上，共享组件通过 28/28 项原生断言和 13/13 项驱动
检查；Host API Lab 通过 31/31 项原生断言及全部 45 项驱动检查。详见
[组件证据](../tools/fixtures/wasm-phone-lab/README.zh-CN.md#最终源码验收)和
[Host API 证据](../tools/fixtures/host-api-lab/README.zh-CN.md#最终源码验收)。
手机使用独立测试包，已安装的 Home 保持不变。真实模型行为与 OpenHarmony 设备执行
仍**未验证**。

单元测试、模拟连接器、平台测试、实体设备测试和发布产物必须分别记录。
构建成功或 PR 合并不代表设备验收通过。组件支持见 [WebAssembly 说明](wasm.zh-CN.md)，
设备 API 见 [宿主 OS API 状态](host-os-api-status.zh-CN.md)。
