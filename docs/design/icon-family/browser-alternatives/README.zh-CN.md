# 浏览器图标备选方案

[English](README.md) | 简体中文

四个方案沿用已批准的 OctoSense 图标设计体系。这些文件用于设计评审；当前已实现的浏览器图标和图标生成器保持原样。

另见[第二组方案：指南针、地球与指针、帆船、搜索镜](set-2/README.zh-CN.md)。

**已选方向：指南针。** 继续查看[四个指南针变体](compass-variations/README.zh-CN.md)。

![四个浏览器方案及尺寸、形状和图标家族对比](comparison.png)

| 方案 | 设计方向 | 取舍 |
| --- | --- | --- |
| [A — 简洁地球](a-open-globe.svg) | 象牙白地球配两条清晰经纬线 | 最简洁，小尺寸辨识度高；属于常见的网页符号 |
| [B — 浏览器窗口](b-browser-window.svg) | 象牙白窗口、薄荷色标签栏和地球轮廓 | 推荐方案：浏览器含义清晰，与现有插画图标家族协调 |
| [C — 轨道](c-orbit.svg) | 象牙白星球、薄荷色陆地和杏色轨道 | 轮廓最独特；也可能让人联想到太空探索 |
| [D — 叠放标签页](d-linked-tabs.svg) | 两个交叠窗口，前景标签页带地球 | 强调多个页面之间的浏览；内部细节较小 |

四个方案均使用已批准的浏览器青色渐变、暖象牙白及少量薄荷色和杏色。可编辑 SVG 原稿采用正方形满幅背景，不预置平台圆角或外部阴影。前景像素均位于中央 66% 安全区域内。

对比图包含当前已实现的图标、64/40/24 像素预览、深浅背景、macOS/Android/iOS 近似外框，以及邮件、日历和表格图标的家族搭配。这些是 librsvg 静态渲染；这些备选方案的生产渲染和设备表现均**未经验证**。

在仓库根目录重新生成：

```sh
python3 docs/design/icon-family/browser-alternatives/build.py
```

此命令已运行，需要 librsvg 的 `rsvg-convert` 和 Pillow。脚本检查 SVG 解析和前景像素边界，并生成四个 SVG 原稿及 SVG/PNG 对比图。生成后的对比图已进行目视检查。
