# Browser — Compass variations

English | [简体中文](README.zh-CN.md)

**Selected direction: Compass (E from set two).** The user selected Compass as
the main design direction. **C5 Night rose was approved on 2026-10-21** and is
now the Browser replacement in the full family. C1–C4 remain earlier studies.

![Four Compass variations alongside the selected base](comparison.png)

## C5 — Night rose

The requested combination uses **C4's ink dial, mint rim and four ticks** with
**C3's four-spoke rose**. The northeast point is ivory; the other spokes use
mint shades, with an ink center pin. C3's rose geometry and 30-degree rotation
are retained, centered on C4's dial. The approved geometry is now generated by
`tools/build_icon_family.py` into the shipping Browser artwork and its Omarchy outline.

![Night rose, with C3 and C4 for comparison](night-rose-preview.png)

[Editable C5 master](c5-night-rose.svg). Rebuild from the repository root:

```sh
python3 docs/design/icon-family/browser-alternatives/compass-variations/night-rose.py
```

This command was run. XML parsing and raster foreground safe-area checks passed;
the static preview was visually inspected at 64/40/24 px, on light and dark
grounds and with approximate platform frames. Production rendering and devices
are **unverified** in this static study. Current production validation is recorded
in the [family guide](../../README.md).

## Earlier variations

| Variation | Treatment | Tradeoff |
| --- | --- | --- |
| [C1 — Essential](c1-essential.svg) | Ivory dial and broad two-tone needle; no ticks | Simplest silhouette and fewest details |
| [C2 — Mint rim](c2-mint-rim.svg) | Mint casing, ivory inset face, four ticks and coral/mint needle | Recommended: a tactile object consistent with the approved family |
| [C3 — Compass rose](c3-compass-rose.svg) | Four-point rose with eight restrained direction markers | Strong navigation character; more internal detail |
| [C4 — Night dial](c4-night-dial.svg) | Ink face, mint casing and ivory/mint needle | Restrained palette and a distinct dark identity |

All four retain the Browser teal gradient and the original Compass's northeast
orientation. Editable SVG masters use square, full-bleed backgrounds without
baked platform corners or outer shadows. Foreground pixels fit inside the
central 66% safe area.

The selected base is shown at the top right. Previews cover 64/40/24 px,
light and dark grounds, approximate macOS/Android/iOS frames, and Mail,
Calendar and Sheets as family context. These are static librsvg renders;
production rendering and devices are **unverified** for these variations.

Rebuild from the repository root:

```sh
python3 docs/design/icon-family/browser-alternatives/compass-variations/build.py
```

This command was run. It reuses the earlier preview builder, requires
`rsvg-convert` and Pillow, validates XML parsing and raster foreground bounds,
and writes four masters and the SVG/PNG comparison. The comparison was
visually inspected. Shipping artwork is unchanged.
