# 紧凑 Mail 编辑器 — 2026-10-05

[English](mail-compact-editor-2026-10-05.md) | 简体中文

用户指出回复控件挤占正文，选中文字会使编辑框变暗。原生 Mail 面板重复显示
Glance 摘要、为查看原邮件单独保留一行、始终展开地址字段，并在保存状态下方
放置整行 Review 按钮。

## 修改

Original、Details 与 Review 共用一行 44 点操作栏。正文仍可直接编辑，Details
展开收件人和主题编辑。紧凑头部标识已保存回复。Glance 摘要保留在信息流，
不再重复占据编辑器上方空间。原邮件头部与正文一起滚动。面板高度不足 320 点时
收起头部预览，仍可通过 Details 打开字段。键盘使视口极短时，聚焦正文编辑临时
收起标题、页签、操作栏和常规已保存提示；Android 返回键或关闭键盘控件恢复
这些内容。错误及冲突状态保持可见，准确邮件审核仍使用独立的宿主批准路径。

输入框配色现在覆盖按下、焦点、禁用及渐变状态。浅色外观在现有浅色编辑框上
使用不透明度为 25% 的 `#829ab5` 选区，深色外观使用不透明度为 28% 的 `#90a6c3` 选区
与浅色文字。选择文字不改变
整个输入框背景。这些修改属于宿主控件，不改变模型生成卡片源码、Mail 草稿
权威数据或实体发送审批。

## 验证

首次几何测试未达到短视口的正文空间要求：220 点面板中正文实测为 128 点高。
随后移除了标签继承的多余内边距；首次失败记录与后续结果分开保留。

构建 2026100519 通过 935 项 Shell 与 55 项 Mail 测试（两个可选 Mail 测试忽略），
以及桌面/手机检查、两种依赖图、固定版本/目录/私有路径检查。原生几何测试中，
700、260 和 220 点高的面板分别提供 620、180 和 140 点正文高度；头部字段按
键盘上方正文编辑状态隐藏。所有操作保留 44 点点击区域。这是原生控件几何数据，
不是屏幕呈现耗时。

首次手机颜色检查失败：整个编辑框已保持浅色，但不透明灰色选区遮住了字形。
该构建不能算选择功能通过。后续修改把选区（包括焦点和按下状态）改为半透明。

键盘上方的紧凑竖屏编辑器，以及 Review/Back。显示的准确回复与保存内容一致。
