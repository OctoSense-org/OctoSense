Install OctoSense

A guided installation for OnePlus 6.

Developer preview. Public installation is not available yet. This preview supports fresh installations; use the phone’s updater for a supported update.

  1. Connect
  2. Verify release
  3. Install
  4. Check boot

Use desktop Chrome or Edge with USB access, local storage and Web Locks. Open this page over HTTPS or localhost.

1. Connect your phone

Enter bootloader mode on the phone, then connect it directly to a USB port on this computer.

Help entering bootloader mode

For OnePlus 6: turn the phone off, then hold Volume Up + Volume Down + Power. Close other tools that are using this phone’s USB connection.

Phone
Bootloader

Unlocking the bootloader erases all apps, accounts and files on the phone. Back up what you need before continuing.

2. Download and verify

All required images are downloaded and verified before installation begins. Keep this tab open while verification runs.

3. Review and install

This fresh installation replaces Android and erases all apps, accounts and files on the phone.

Load a release and connect a phone to begin.

Recovery review required

A previous write may be incomplete. This preview will not replay it or start another ordinary installation. Keep the phone in bootloader mode and review the saved report.

Open recovery instructions

4. Check the phone starts

After all images are written, restart the phone. The first boot can take several minutes.
