OctoSense Installer

Installs or updates the OctoSense ROM on a OnePlus 6 from this browser over USB. Chrome or Edge on a computer; no adb or fastboot needed.

1. Put the phone in bootloader mode

  1. Power off, then hold Volume Up + Volume Down + Power until the bootloader screen appears.
  2. Plug the phone into this computer.
  3. First install only: the bootloader must be unlocked (OEM unlocking in Developer options, then Unlock below; this wipes the phone).

2. Connect

This browser has no WebUSB. Use Chrome or Edge.
