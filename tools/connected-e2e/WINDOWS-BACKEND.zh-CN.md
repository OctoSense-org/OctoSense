# Windows 开发者后端登录验收

[任务 37730564370](https://github.com/OctoSense-org/OctoSense/actions/runs/37730564370)
通过了真实 Windows Credential Manager 生命周期检查，以及原生 OctoSense
测试宿主、已有 Edge 浏览器和合成 HTTP 后端之间的完整登录流程。
[不可变验收记录](evidence/windows-backend-37730564370.json) 保存了二进制哈希、
原始记录哈希、35 个与已审阅源码一致的文件哈希和七项通过结果。

七项行为包括：浏览器注册与密码登录、真实 PKCE 回调及受保护数据访问、
轮换刷新凭据后的故障恢复、原生进程重启后从系统凭据库恢复连接、退出与再次
登录、两个已签名应用之间的账号句柄隔离，以及撤销两个虚构连接。所有自有
原生进程和合成服务器均已停止。凭据删除通过真实宿主断开连接接口请求；
本流程没有额外读取系统凭据库来独立确认删除。

实际工作流检出的是合并提交 `95d1da069c01cebdb585eca3e75354e58833abd8`，
PR 分支提交为 `723b202e76c62473aa0d95f16a58f38553a2882d`。原始记录误将
OctoSense 检出版本字段命名为 `runtime_base_commit`；公开记录明确了这个
含义，不能把它当作 Makepad 版本。

测试使用临时签名、真实 Store 安装和全新的浏览器上下文，没有向宿主注入
账号或令牌。浏览器打开的是测试宿主从自己的原生授权链接复制出的精确 URL；
**没有测试操作系统默认浏览器的链接点击**。此结果也不证明 Windows 视觉 UX、
Google/GitHub 真实账号登录，或经人和操作系统认证后执行写入。原始回调 URL、
配置及诊断文件保持私有。复现命令见 [英文驱动说明](README.md#native-backend-browser-acceptance-2026-10-08)。
