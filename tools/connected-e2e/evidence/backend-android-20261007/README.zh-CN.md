# Android 后端登录结果

[English](README.md) | 简体中文

[脱敏回执](receipt.json) · [复现方法](../../ANDROID-BACKEND.zh-CN.md)

在真实 OnePlus 6／Android 15 上，完成了开发者后端 HTML 表单注册／登录、PKCE 回调、令牌交换、身份查询、原生凭据库冷启动恢复和退出登录。没有注入已登录账号或令牌。最终 APK 还完成了展开 Glance 卡片中的原生取消和真实登录回调。

Glance 流程暴露并修复了生命周期缺陷：事件处理保留了 Android 登录交接，但绘制路径仍提前销毁宿主页。最终版本同时保留两条路径。登录成功会切换活动连接，使旧账号绑定的卡片失效；截图显示回到普通 Glance 页面，不冒称已销毁卡片上出现了成功消息。

[取消返回](glance-cancel.png)、[登录返回](glance-after-login.png) 和[退出登录](logged-out.png) 均为最终 APK 的原始 ADB 截图。手机上的普通测试界面存在标题／状态布局裁切，因此不代表完整 UX 验收通过。

原生登录窗口启用 `FLAG_SECURE`，不能截图；证据为原生控件层次、实际表单输入及协议结果。较早两次普通应用登录返回时，ADB 截图全黑，而配对的 Makepad GPU 纹理正常。这区分了应用绘制和系统截图，但不能证明物理屏幕上实际显示了什么。最终 Glance 返回的 ADB 截图正常，之前的截图限制仍未解决。

回执分别列出最终 APK 验证、同一实验的早期验证、保留失败和未运行项目。Android 导航／网络负面用例、真实 Google／GitHub 和生产 HTTPS 后端未在本次手机实验验证；Mac 和协议测试不能代替手机证据。仅停止了自己的测试包／服务并移除自己的反向端口映射。隔离测试包仍保留两个历史虚构连接，但没有活动账号。
