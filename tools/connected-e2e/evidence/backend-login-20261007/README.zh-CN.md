# 原生后端登录证据

[English](README.md) | 简体中文

**通过：七项功能检查及八张逐张审视的原始截图。** 测试使用本机 HTTP 模拟后端、实际独立 Chrome 会话，以及真正的 macOS 原生宿主、回调监听器和平台凭据保险库。没有预先注入账号、授权码或令牌。[回执](receipt.json) 包含二进制及源码哈希、签名安装信息、脱敏服务器事件和图片哈希。[复现说明](../../backend-login/README.zh-CN.md) 介绍仅供测试的浏览器交接及构建方法。

注册、登录、受保护身份读取、刷新失败恢复、进程冷启动、退出、再次登录和两个签名应用之间的隔离均通过。两个本地连接均通过宿主撤销；已请求平台保险库删除凭据，未独立读回验证删除结果。自行启动的原生进程和服务器全部停止，输入重放和 instrument 只读重试均为零。三条浏览器控制台错误均来自自动请求 `/favicon.ico`，不是 CSP 错误或授权回调失败。

以下图片均为未经修改的原图。邮箱样式的标签为虚构身份，后端回环端口为临时端口。没有包含提供商注册资料、个人账号、回调查询参数、密码、授权码、令牌、应用配置目录或原始日志。

[先前尝试](prior-attempts.json) 保留失败、源码和二进制哈希：第 1–2 次发现并确认模拟服务器的 CSP 缺陷，第 3 次发现测试驱动未等弹层关闭的问题，第 4 次已通过，最后一次进一步分类浏览器控制台错误。没有将失败尝试记为通过。

这些证据不代表 Android 后端回调或嵌入式 WebView 登录通过。真实 GitHub/Google 验收另行记录。此夹具不是生产应用的 UX 设计，也不是公开发布的 App Hub 应用。
