# Notes Rinx 写作界面原生持续测试

[English](README.md) | 简体中文

两轮脚本任务与状态保留检查均通过：先完成 **36 轮、601.819 秒**，再完成
**12 轮、10.272 秒**。测试在 macOS 使用签名安装的 GitHub Notes、集成原生宿主、
隔离的虚构 GitHub 服务，以及 Makepad instrument 输入事件。下列 8 张发布截图均逐张检查了
原始分辨率。这是手机宽度的桌面窗口，不是 OnePlus 6 物理输入或 Android 验收。

| 证据 | 长时间测试 | 最终快速测试 |
| --- | --- | --- |
| 记录 | [long-36-receipt.json](long-36-receipt.json) | [final-12-receipt.json](final-12-receipt.json) |
| 轮数 | 36 | 12 |
| 总时间，含启动及重新打开 | 601.819 秒 | 10.272 秒 |
| 轮内空闲/定时器观察 | 572.209 秒 | 0 秒 |
| 精确内容审核并取消 | 6 次 | 2 次 |
| 富文本修改并撤销 | 6 次 | 2 次 |
| 新进程重新打开并核对完整草稿 | 1 次 | 1 次 |
| 外部服务写入尝试 | 0 次 | 0 次 |

36 轮长测在 Notes Splash 的加载失败恢复保护修改**之前**完成；最终 12 轮在该保护和
应用包清单更新**之后**完成。两轮使用相同原生二进制 `a4a11541…c75522`，记录中的 Rust
编辑器、宿主、驱动源码哈希相同；应用包 `main.splash`、`manifest.json` 哈希不同，因此分别保留记录。
最终快速测试重复正常任务路径，没有故意制造远程加载失败，不能单独证明该失败处理分支。

每轮交替写入长短虚构 Markdown，包含带重音的拉丁字母、中文和日文；随后滚动并重新聚焦源码，
进入辅助块编辑器、预览文档，再访问仓库界面并返回。每六轮修改一个富文本块并撤销，
核对完整持久化草稿，打开准确版本的宿主审核，滚到末尾后取消。最终通过新原生进程重新打开
已安装应用并再次核对整份草稿。所有测试进程退出码为 0，驱动删除了隔离资料目录。
没有使用真实 GitHub 凭据，也没有执行远程写入。

以下数值是 **instrument 往返时间**，包含原生帧等待、IPC、轮询和该操作本身的工作。
它们不是 FPS、触摸到显示的延迟，也不是空闲机器基准。源码修改和持久化读回还包含应用
350 ms 的本地保存防抖；进入块编辑器包含经由预览和样式面板的多步操作。

| 操作 | 长测 P95 / 最大值 | 最终快速测试 P95 / 最大值 |
| --- | --- | --- |
| 源码修改及持久化读回 | 485.74 / 711.74 ms | 441.43 / 441.46 ms |
| 源码滚动及重新聚焦 | 11.31 / 13.20 ms | 7.65 / 7.67 ms |
| 进入块编辑器 | 42.75 / 75.98 ms | 22.48 / 23.85 ms |
| 切换预览 | 13.14 / 102.13 ms | 8.28 / 9.34 ms |
| 预览往返滚动 | 21.45 / 42.07 ms | 15.88 / 20.73 ms |
| 仓库界面及返回 | 83.68 / 236.39 ms | 50.77 / 57.27 ms |
| 打开精确内容审核 | 196.21 / 212.62 ms | 125.65 / 126.39 ms |
| 取消审核 | 14.84 / 15.95 ms | 11.92 / 12.16 ms |

审核时间分别只有 6、2 个样本。新进程启动至恢复状态标签出现分别为 409.15、360.82 ms，
各一个样本；之后立即核对完整草稿相等。

两轮有限时长测试的 RSS 均增长。长测逐轮样本从 **316.23 增至 370.44 MiB**，
最后空闲样本为 364.42 MiB；前五轮/后五轮中位数为 326.14/363.64 MiB。
快速测试从 **316.94 增至 353.95 MiB**，前五轮/后五轮中位数为 321.62/341.27 MiB。
RSS 包含渲染缓存、编辑历史和截图分配。这些有限样本既不能证明内存泄漏，也不能保证不存在
泄漏或已达到稳定状态；每个数值样本均保留在记录中。
