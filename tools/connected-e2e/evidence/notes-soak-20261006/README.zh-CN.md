取消，以及两次已安装应用重启。每轮均核对权威持久化 Unicode Markdown；没有崩溃、
原生严重错误日志、草稿丢失或供应商写入尝试。四个自有进程正常退出，且已确认临时
配置目录清理。此次测试没有修改应用或运行时。

虚构测试依赖，没有真实 OAuth 或仓库写入。

这里计量的是包含原生帧提交等待、控制器轮询和编辑保存防抖的 HTTP instrument 往返，
不是 FPS、单个按键延迟或真实输入到显示延迟。同一 Mac 同时运行 Inbox/Calendar 浸泡
及四个构建作业的 Android 交叉编译。

内存并非恒定。密集循环中，56–60 轮的 RSS 中位数为 359.2 MiB，86–90 轮为 360.9 MiB，
111–119 轮为 371.4 MiB；最后截图又出现分配台阶。追加测试超过 Rinx 文档撤销历史的
100 条上限，但没有分别分析历史、分配器/渲染缓存及审核/截图分配，因此不能据此证明
有无泄漏。每次测试的 `cycles.csv` 和回执保留原始逐轮测量，将增长作为后续分析事项。
